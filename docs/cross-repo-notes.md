# Cross-Repo Notes

An append-only log for surfacing things worth sharing with the sibling repos
(`personal`, `professional`). Each repo has its own copy of this file; a Claude
session in any sibling reads the others at session start (they sit side by side
under `#Repositories`).

## How to use it

- **Writing:** when you notice something another repo should know — a convention,
  a tooling fix, a setup gotcha, a suggested edit to their README/CLAUDE.md —
  append an entry below, tagged with the target repo (`→ personal`, `→ professional`,
  or `→ all`). Don't edit another repo's files directly; propose here.
- **Reading:** at session start, if the work touches conventions/tooling/setup,
  scan the siblings' copies of this file for unresolved entries tagged for *this*
  repo (`→ academics`) and surface them.
- **Resolving:** when an entry has been acted on, mark it `[x]` and add a one-line
  outcome. Leave the entry in place as a record.

## Format

```
- [ ] YYYY-MM-DD → <target> | <short summary>
      <detail: what to change and why>
```
